Opzioni di configurazione per le cronologie

È possibile regolare l’aspetto e il comportamento delle cronologie per soddisfare al meglio le proprie esigenze.

È possibile selezionare:

  • Quali tipi di registrazione e altri elementi devono essere mostrati sulle cronologie? Ad esempio, selezionare per mostrare audio registrato e segnalibri.

  • Come riprodurre gli spazi tra le registrazioni.

  • Per nascondere la cronologia principale durante l’inattività per liberare la maggior parte del display per la visualizzazione di video.
