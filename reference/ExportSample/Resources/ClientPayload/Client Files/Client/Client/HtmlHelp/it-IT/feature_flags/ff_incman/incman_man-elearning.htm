Questa documentazione e i corsi eLearning

Questa documentazione descrive come raccogliere prove giuridiche solide con le funzioni di XProtect Incident Manager.

Milestone propone corsi eLearning per tutti i prodotti XProtect. Visita il Milestone Learning Portal all’indirizzo https://learn.milestonesys.com/index.htm.

Per trovare i corsi XProtect Incident Manager, cerca incident manager. Il corso Using XProtect Incident Manager è rivolto agli operatori di XProtect Smart Client, mentre il corso Configuring XProtect Incident Manager è rivolto agli amministratori di XProtect Management Client.
