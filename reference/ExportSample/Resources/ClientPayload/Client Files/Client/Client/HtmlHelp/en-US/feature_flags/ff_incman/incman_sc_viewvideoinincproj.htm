View video in an incident project

You and your colleagues can view the video added to an incident project. For example, to remind yourself of the incident, to see it for the first time, or compare the evidence in an old incident project with those in a new and perhaps related incident project.

  1. Select the Incidents tab and double-click the incident project with the video that you want to view.
  2. Select the Sequence list tab.
  3. Select the View video button.
  4. From the list of sequences in the bottom-right corner of the window, select the sequence you want to view.
  5. Select to play the video forward.
