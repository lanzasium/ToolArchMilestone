Informazioni generali sulle estensioni

Milestone ha sviluppato varie estensioni. Le estensioni sono prodotti che estendono le funzionalità dei prodotti XProtect VMS con ulteriori funzionalità specializzate. Il file della XProtect licenza determina anche l'accesso alle estensioni.

Poiché XProtect è una piattaforma aperta, anche le estensiopni di terze parti possono essere integrate con il VMS XProtect per aggiungere funzionalità a XProtect Smart Client.

Le funzionalità disponibili dipendono dal sistema in uso. Consultare l’elenco completo delle funzioni, disponibile nella pagina di panoramica sul prodotto sul sito web Milestone (https://www.milestonesys.com/products/software/product-index/).

In XProtect Smart Client, l'accesso alle funzionalità dalle estensioni dipende anche dalle autorizzazioni di cui dispone l'utente.
