Configure how to play back gaps between recordings

You can adjust how the main timeline plays back gaps between recordings.

If, for example, all cameras in a view have no recordings in the same period, there is no need to play back the non-recordings at normal speed. Therefore the timeline is, by default, configured to skip playback of gaps between recordings. If you want to change this behavior, you can.

  1. From the global toolbar, select the Settings and more menu and then Settings.

  2. From the Settings window, select Timeline.

  3. Set the Playback option to either Skip gaps or Do not skip gaps.
