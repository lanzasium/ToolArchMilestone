Define to restore windows and tabs when logging in

To have your workspace arranged as you prefer when you have logged in, you can define if you want to restore the windows and tabs left open when you last logged out of XProtect Smart Client.

  1. From the Settings and more menu, select Settings.

  2. From the Application tab, open the dropdown menu for the Restore windows and tabs setting.

  3. Select the option that suites you best:

    • Last: Always restore all windows and tabs you had open when you logged out of XProtect Smart Client.

    • None: Never restore any windows and tabs you had open when you logged out of XProtect Smart Client.

    • Ask: When logging in, you are asked if you want to restore your XProtect Smart Client windows and tabs from last session.
