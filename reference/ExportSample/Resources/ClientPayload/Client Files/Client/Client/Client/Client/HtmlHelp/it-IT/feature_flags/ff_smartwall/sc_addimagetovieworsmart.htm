Aggiungere un'immagine alla vista o allo Smart Wall

È possibile visualizzare immagini statiche in una vista o su uno o più Smart Wall. Ciò è utile, per esempio quando si desidera condividere un'istantanea di un sospetto, o una mappa delle uscite di emergenza.

Se si condivide un'immagine con utenti o Smart Wall che non hanno accesso alla posizione su rete del file di immagine, la si può inserire. Quando si inserisce un'immagine, la si memorizza nel Smart Client ed il collegamento alla posizione del file originale viene rimosso. Se si rimuove o sostituisce un'immagine inserita da uno Smart Wall e la si vuole visualizzare di nuovo, è necessario aggiungere di nuovo il file di immagine allo Smart Wall.

Operazioni:

  1. Fare clic sul pulsante Impostazioni per entrare nella modalità Impostazioni.
  2. Nel riquadro Panoramica di sistema trascinare l'elemento immagine sulla posizione nella vista.
  3. Selezionare il file dell'immagine da aggiungere e fare clic su Apri.
  4. Per rendere l'immagine disponibile ad altri utenti che non possono accedere alla posizione del file di immagine, fare clic su Inserisci nel riquadro Proprietà. Il file è archiviato nel sistema.
  5. Per inviare l'immagine a Smart Wall, fare clic su Altro > Invia a Smart Wall nella barra degli strumenti dell'elemento della vista.
  6. Selezionare lo Smart Wall, il monitor e il riquadro nel quale si vuole che l'immagine appaia.
  7. Ripetere i passi 5-6 per ogni Smart Wall a cui si desidera inviare l'immagine.
