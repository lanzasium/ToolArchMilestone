First time you log in (explained)

The first time you log in, you need to determine whether any views exist. Views determine how video is displayed and are required to use XProtect Smart Client. One or more views may already have been created for you, or you may need to create views yourself. Read more about views - including how to determine if views have already been created for you, in Views (explained).

Your user settings (including views) are stored centrally on the surveillance system. This means that your login can be used on any computer that has a Smart Client installed, and that you can restore views from your last log-in.

If you encounter a second dialog box during login, you need additional login authorization (see Login authorization (explained)) to get access to the XProtect Smart Client.
