Tabs in XProtect Smart Client

The XProtect Smart Client has the following tabs:

  • The Live tab (see Live tab (explained)) for viewing live video
  • The Playback tab (see Playback tab (explained)) for viewing recorded video
  • The Search tab (see Search for video) for making advanced searches for video and metadata.
  • The Alarm Manager tab (see Alarm Manager tab (explained)) for investigating incidents and alarms
  • The System Monitor tab (see System Monitor tab (explained)) for viewing system information

If some of the tabs are unavailable, it is because you do not have the rights required to access all the areas.

These tabs are visible only if you have acquired licenses for XProtect Transact, XProtect LPR, or XProtect Access:

  • The Access Control tab (see Access Control tab (explained)) for controlling your access control system and associated cameras.
  • The LPR tab for (see LPR tab (explained)) identifying vehicles by their license plates, and investigating LPR related events.
  • The Transact tab for (see Transact tab (explained)) monitoring and investigating transactional data in combination with the associated video streams.
