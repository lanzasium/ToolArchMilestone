Modifica disposizione dei monitor Smart Wall

Esistono svariati metodi per modificare la disposizione dei monitor e il modo in cui viene disposto il contenuto.

Applicazione di una disposizione differente sul monitor di uno Smart Wall
  • In una panoramica Smart Wall, fare clic sulla icona per il monitor, selezionare Cambia layout di vista, selezionare il formato del display (per esempio, 4:3 o 16.9) e quindi selezionare il layout.

Applicazione di un predefinito differente

È possibile selezionare una preimpostazione Una disposizione predefinita di un monitor singolo in XProtect Smart Client. differente per la panoramica Smart Wall. Tuttavia, modificando la preimpostazione si potrebbero modificare tutti i monitor in Smart Wall.

  • Se si desidera applicare un predefinito differente, usare il menu Selezione predefiniti

Altri utenti possono modificare manualmente i predefiniti, o le regole li possono modificare automaticamente.
