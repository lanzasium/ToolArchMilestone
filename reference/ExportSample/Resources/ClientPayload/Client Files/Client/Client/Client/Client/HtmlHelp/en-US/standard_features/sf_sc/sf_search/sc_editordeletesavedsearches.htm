Edit or delete saved searches

This feature is only available in certain surveillance systems.

  • Overview of the key features in your system: https://www.milestonesys.com/solutions/platform/product-index/
  • Detailed product comparison chart (search for comparison chart): https://content.milestonesys.com/media

You can change the details of a saved search, or you can change how the search is configured, for example the search categories.

If the searches become obsolete, you can delete them.

Steps:

  1. To edit the details of a saved search:

    1. On the Search tab, click to the right of Search filters.

    2. In the list that appears, click Manage searches. A window appears.
    3. Find and select the search that you want to change.
    4. Make your changes, for example the name of the search, and click Save.
  2. To delete a saved search:
    1. Open the Manage searches window as described in step 1.1-1.2.
    2. Find and select the search that you want to delete.
    3. Click Delete search.
  3. To change how a saved search is configured:

    1. On the Search tab, click to the right of Search filters.

    2. In the list that appears, click Open search. A window appears.

    3. Find and double-click the search that you want to open, or click Open. Immediately the search is run.

      If many searches are listed, use the search function to find the search.

    4. Modify the search, for example by adding cameras, and click > Save.
