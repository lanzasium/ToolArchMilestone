Overview of XProtect Smart Client – Player

Investigate the exported recordings on the Playback tab, and run searches on the Search tab (see Search in XProtect Smart Client – Player).

Select the view that contains the cameras that you are interested in.

Drag the timeline back and forth to browse the recorded video. See Timeline (explained).

Use the time navigation controls to play back video or jump to a specific moment in time. See Time navigation controls (explained).

Change the timespan. The range is five minutes to four weeks.

Zoom in or out.

Copy a still imageA single static image. to the clipboard, so you can paste it into, for example, a document, or print a surveillance report with a still image and related information.

Start search in a new search window with the cameras in the current view preselected.
