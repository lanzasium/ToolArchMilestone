Schede in XProtect Smart Client

XProtect Smart Client presenta le seguenti schede:

  • Scheda Live (vedere Scheda Live (spiegazione)) per la visualizzazione del video live
  • Scheda Riproduzione (vedere Scheda Riproduci (spiegazione)) per la visualizzazione dei video registrati
  • La scheda Ricerca (vedere Ricerca di video) per le ricerche avanzate di video e metadati.
  • Scheda Alarm Manager (vedere Scheda Alarm Manager (spiegazione)) per acquisire informazioni sugli incidenti e sugli allarmi
  • Scheda System Monitor (vedere Scheda System Monitor (spiegazione)) per la visualizzazione delle informazioni di sistema

Alcune schede potrebbero non essere disponibili qualora l’utente non disponga dei diritti necessari per accedere a tutte le aree.

Queste schede sono visibili solo se sono state acquistate licenze per XProtect Transact, XProtect LPR o XProtect Access:

  • Scheda Controllo accessi (vedere Scheda Controllo accesso (spiegazione)) per esaminare il sistema di controllo accessi e le telecamere associate.
  • Scheda LPR (vedere Scheda LPR (spiegazione)) per identificare i veicoli in base alle targhe e per analizzare gli eventi collegati a LPR.
  • Scheda Transact (vedere Scheda Transact (spiegazione)) per monitorare e indagare sui dati transazionali in combinazione con i relativi flussi video.
