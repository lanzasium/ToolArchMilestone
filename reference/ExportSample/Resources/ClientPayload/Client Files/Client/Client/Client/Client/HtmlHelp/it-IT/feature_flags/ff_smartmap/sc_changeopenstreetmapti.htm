Modifica del server delle sezioni di OpenStreetMap

È possibile specificare un server delle sezioni diverso per OpenStreetMap rispetto al server standard specificato nella configurazione per uno specifico tipo di profilo utente. Per esempio, se il VMSAbbreviazione di "Video Management Software o software di gestione video". non è connesso a Internet, è possibile utilizzare un server locale. Oppure, è possibile utilizzare un server commerciale.

Requisiti

Se per il server delle sezioni specificato nella configurazione è stata bloccata la modifica, il campo viene disabilitato in XProtect Smart Client e non è possibile modificarlo. Contattare il proprio amministratore di sistema per supporto nell'abilitare la funzione sul profilo Smart Client su Management Client.

Operazioni:

  1. Nell’angolo in alto a destra, fare clic su , quindi su Impostazioni per aprire la finestra di dialogo Impostazioni.

  2. Nella sezione sinistra, fare clic su Smart Map.
  3. Nel campo Server delle sezioni alternativo OpenStreetMap, eseguire una delle seguenti operazioni:
    • Inserire l'indirizzo del server. Se il campo è inattivo, è stato bloccato nella configurazione
    • Per utilizzare il server specificato nella configurazione, selezionare la casella di controllo Segui server
  4. Fare clic su OK. Lo sfondo geografico viene modificato.

Per ulteriori informazioni, vedere Modifica del server selle sezioni di OpenStreetMap.
