Copia di singole immagini

È possibile copiare singole immagini statiche da telecamere selezionate. Le immagini copiate possono poi essere incollate (come immagini bitmap) in altre applicazioni, come word processor, client di e-mail ecc. È possibile copiare solo una singola immagine da una singola telecamera in ciascuna operazione.

  • Sulla barra degli strumenti della telecamera, fare clic sull'icona Copia negli Appunti per copiare un'immagine
