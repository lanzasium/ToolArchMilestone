Installare XProtect Smart Client

Prima dell'utilizzo, installare XProtect Smart Client sul computer in uso. È possibile scaricare XProtect Smart Client dal server del sistema di sorveglianza e installarlo sul computer.

Milestone In generale, consiglia di utilizzare la versione più recente di XProtect Smart Client per accedere alle nuove funzionalità del sistema di sorveglianza XProtect.

  1. Aprire il browser e collegarsi al server di gestione utilizzando il relativo URL o indirizzo IP del server.
  2. Eseguire una delle seguenti operazioni:
    • Server locale (http://localhost/installation)
    • Indirizzo IP del server remoto (http://[IP_indirizzi]/installazione)
  3. Nella pagina di benvenuto, fare clic su Lingua e selezionare la lingua da utilizzare. Verrà avviata l'installazione guidata di XProtect Smart Client.
  4. Seguire le istruzioni della procedura guidata visualizzata su schermo. La procedura guidata suggerisce un percorso di installazione. Normalmente è possibile utilizzare il percorso di installazione suggerito. Tuttavia, se l'utente ha già utilizzato prodotti aggiuntivi, il percorso potrebbe non essere più valido.
