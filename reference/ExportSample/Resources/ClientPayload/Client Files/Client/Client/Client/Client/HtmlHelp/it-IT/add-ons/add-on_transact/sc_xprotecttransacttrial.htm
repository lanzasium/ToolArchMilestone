Licenza di prova di XProtect Transact

La licenza di prova di XProtect Transact consente di utilizzare le funzionalità di XProtect Transact per un massimo di 30 giorni. Tutte le funzioni correlate sono attive ed è possibile aggiungere fonti delle transazioni (es. registratori di cassa). Una volta scaduto il periodo di prova di 30 giorni, vengono disattivate tutte le funzioni di XProtect Transact, compresi l'area di lavoro Transact e gli elementi delle viste delle transazioni. Acquistando e attivando una licenza base di XProtect Transact e le licenze delle fonti delle transazione necessarie, è possibile utilizzare nuovamente XProtect Transact con i medesimi dati e le medesime impostazioni della versione di prova.

Se si utilizza XProtect Express o XProtect Professional, la licenza di prova è una licenza integrata. La licenza di prova viene attivata quando l'amministratore di sistema aggiunge fonti delle transazioni alla configurazione.

Per gli altri prodotti, occorre acquisire la licenza di prova da Milestone. L'amministratore di sistema deve attivare la licenza di prova nella configurazione.
