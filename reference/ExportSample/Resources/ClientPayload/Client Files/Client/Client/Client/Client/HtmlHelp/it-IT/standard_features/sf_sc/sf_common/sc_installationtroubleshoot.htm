Installazione (risoluzione dei problemi)

Questi sono i messaggi di errore che si possono incontrare mentre si tenta di accedere a XProtect Smart Client:

Non è possibile installare MilestoneXProtect Smart Client (64-bit) su questo sistema operativo. Il sistema operativo non è supportato.

Si è tentato di installare una versione di XProtect Smart Client che non supporta la versione corrente del sistema operativo Windows del computer. Per risolvere il problema, installare una versione precedente di XProtect Smart Client o aggiornare il sistema operativo.

Per informazioni relative ai requisiti minimi di sistema, visitare il sito Web di (https://www.milestonesys.com/systemrequirements/).
