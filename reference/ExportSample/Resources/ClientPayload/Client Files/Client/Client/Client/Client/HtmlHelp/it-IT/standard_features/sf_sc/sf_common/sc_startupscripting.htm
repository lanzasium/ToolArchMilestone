Scripting per l'accesso (spiegazione)

Lo scripting può essere utilizzato per controllare alcune parti o l'intera procedura di accesso a XProtect Smart Client.

Esempi:

  • Se si utilizza l'autenticazione di base o l'autenticazione di Windows, è possibile aprire la finestra di login di XProtect Smart Client con un indirizzo server e campi nome utente pre-compilati in modo che gli utenti debbano solo inserire una password per accedere.
  • Se si utilizza l' autenticazione Windows (utente attuale), è possibile effettuare automaticamente la connessione di XProtect Smart Client al sistema di sorveglianza, in base al login Windows attuale dell'utente.

Sono disponibili alcuni metodi di autenticazione solo se l'utente di XProtect Smart Client effettua l'accesso a determinati sistemi di sorveglianza Milestone
