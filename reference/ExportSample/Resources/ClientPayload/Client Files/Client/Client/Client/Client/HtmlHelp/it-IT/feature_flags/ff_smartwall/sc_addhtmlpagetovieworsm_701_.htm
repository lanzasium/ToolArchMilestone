Aggiunta di una pagina HTML a una vista o a uno Smart Wall

È possibile aggiungere pagine HTML alle viste e allo Smart Wall. Ciò è utile, ad esempio, per visualizzare istruzioni, pagine web di un'azienda, servizi di mappe su internet, raccolte di collegamenti, pagine di e-learning e altro.

Operazioni:

  1. Fare clic su Configurazione per accedere alla modalità configurazione.
  2. Nel riquadro Panoramica sistema, fare clic e trascinare l'elemento Pagina HTML nella vista. Apparirà la schermata Apri URL.

  3. Nel campo Apri immettere la posizione della pagina HTML richiesta (ad esempio, http://www.mywebsite.com/mywebpage.htm).

    Oppure, se la pagina HTML è archiviata a livello locale sul computer in uso, eseguire una delle seguenti operazioni:

    • Specificare la sua posizione sul computer (ad esempio: C:\myfiles\mywebpage.htm)
    • Fare clic su Sfoglia per cercare la pagina HTML desiderata.
  4. Fare clic su OK.
  5. Fare clic di nuovo su Configurazione per uscire dalla modalità configurazione.
  6. (opzionale) Per impostare le proprietà, fare riferimento alla sezione Impostazione delle proprietà di una pagina HTML.
  7. Per visualizzare la pagina HTML su Smart Wall, fare riferimento alla sezione Visualizzazione di una pagina HTML su uno Smart Wall.
