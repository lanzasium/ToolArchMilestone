Synchronize time on Playback tab with search time

When you are previewing a search result on the Search tab, you can synchronize the time on the Playback tab with the time in the preview timeline. This is useful if, for example, you have found an incident, and you want to investigate what happened at that time on other cameras.

  1. On the Search tab, select a search result.

  2. In the preview area, click to synchronize the time on the Playback tab with the current preview time.

  3. To check other related cameras, click the Playback tab and select a view that contains the cameras that you are interested in. The timeline is now in sync with the search result.
