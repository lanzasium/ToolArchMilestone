Surveillance system differences

Most of the features available in XProtect Smart Client are available in all versions of the XProtect products, but some features work differently depending on what XProtect product you are using. If in doubt, ask your system administrator.

For an overview of the key features available on your particular system, see https://www.milestonesys.com/solutions/platform/product-index/.
