Il TCP è spesso abbinato a un altro protocollo, IP (Internet Protocol). La combinazione dei due, conosciuta come TCP/IP, permette di inviare pacchetti dati avanti e indietro tra due punti sulla rete per periodi di tempo più lunghi ed è usata per connettere computer e altri dispositivi su Internet. e la Password per il trasferimento del video attivato da Matrix dal server di sorveglianza alla vista di XProtect Smart Client. Tale funzionalità è disponibile solo quando viene selezionata la posizione Matrix1: le altre posizioni Matrix erediteranno le impostazioni di connessione specificate per la posizione 1. Per impostazione predefinita, la porta TCP utilizzata per Matrix è la 12345. Chiedere all'amministratore del sistema di sorveglianza di fornire il numero di porta o la password da utilizzare.
