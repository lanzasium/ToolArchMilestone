Evidence lock settings

Name

Description
Headline

The headline of the evidence lock.
Description

A description of the evidence lock.
Evidence lock interval start

Adjust the start date and time for the video sequences you want to protect.
Evidence lock interval end

Adjust the end date and time for the video sequences you want to protect.
Keep evidence lock for

Specify for how long you want to keep the evidence protected.

Depending on you user rights, you can have the following options: hour(s), day(s), week(s), month(s), year(s), indefinite or user-defined.

If you select User-defined, click the calendar button to select a date and then adjust the time manually.

When done, the date and time for when the evidence lock expires is shown.
Select camera

Click to select more cameras to include in the evidence lock.
Remove/Remove All

Click to remove one selected camera or all cameras from the evidence lock.
