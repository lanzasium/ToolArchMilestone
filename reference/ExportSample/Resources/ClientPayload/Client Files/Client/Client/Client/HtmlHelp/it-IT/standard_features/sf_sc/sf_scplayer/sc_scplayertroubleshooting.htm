Esportazione (risoluzione dei problemi)

Ho ricevuto un'esportazione, ma non riesco ad eseguire il file SmartClient-Player.exe o Exported Project.scp

L’esportazione potrebbe essere stata creata su un computer con sistema operativo Windows a 64 bit, mentre il computer in uso possiede un sistema operativo a 32 bit.

Per risolvere il problema, provare una o più delle seguenti opzioni:

  • Aprire il file SmartClient-Player.exe su un computer con Windows a 64 bit.
  • Aprire l'esportazione con una versione a 32 bit di XProtect Smart Client. A tale scopo, procedere come segue:
    1. Aprire questo collegamento: https://www.milestonesys.com/downloads/.
    2. Selezionare Prodotto, ad esempio XProtect Corporate, Versione e Lingua.
    3. Fare clic su XProtect Smart Client 32-bit per scaricare l'applicazione.
    4. Una volta installato, andare nella cartella di esportazione e aprire la cartella File client.
    5. Fare doppio clic sul file Project.scp esportato. XProtect Smart Client – Player si apre ed è possibile riprodurre il video.
  • Chiedere alla persona che ha fornito l'esportazione di creare una nuova esportazione utilizzando XProtect Smart Client a 32-bit.
  • Chiedere alla persona che ha fornito l'esportazione di creare una nuova esportazione utilizzando un diverso formato di esportazione, ad esempio AVI o MKV.

Il problema potrebbe verificarsi anche se l'esportazione è stata creata utilizzando un algoritmo di crittografia diverso da quello della versione attuale di XProtect Smart Client. Vedere anche Almeno un file del database utilizza un algoritmo di crittografia non supportato.

Messaggi di errore e avvisi

Almeno un file del database utilizza un algoritmo di crittografia non supportato

Il sistema VMS XProtect attuale utilizza AES-256 per la crittografia dei dati video esportati, nel rispetto dello standard di sicurezza FIPS 140-2Uno standard governativo statunitense che definisce i parametri di sicurezza critici che i fornitori devono utilizzare per la crittografia prima di vendere software o hardware agli enti governativi statunitensi.. Tuttavia, il sistema utilizzato per creare l'esportazione sfrutta uno standard di crittografia differente.

Per risolvere il problema, effettuare una delle seguenti operazioni:

  • Esportare di nuovo i dati video utilizzando una versione aggiornata di XProtect Smart Client. La versione deve essere pari o superiore alla versione attuale
  • Sebbene Milestone consigli sempre di utilizzare l'ultima versione di XProtect Smart Client, è possibile aprire l'esportazione utilizzando una versione precedente di XProtect Smart Client in modalità offline
  • Aprire l'esportazione su un computer dove la modalità FIPS è disabilitata. Vedere anche https://docs.microsoft.com/en-us/windows/security/threat-protection/fips-140-validation#using-windows-in-a-fips-140-2-approved-mode-of-operation

Milestone consiglia di proteggere con password i dati. Per farlo, selezionare la casella di controllo Crittografa con password nella finestra Esporta.

Impossibile convalidare l'integrità del progetto...

Nell'esportazione video non sono incluse chiavi anti-manomissione. La chiave anti-manomissione è stata rimossa o l'esportazione video è stata creata come applicazione di terze parti indipendente basata su MIP SDKIncidente definito sul sistema di sorveglianza per attivare un allarme in XProtect Smart Client. Se la propria organizzazione usa questa funzionalità, gli allarmi attivati saranno visualizzati in viste contenenti elenchi di allarmi o mappe. 2020 R2 o versione precedente. Se la chiave anti-manomissione è assente, non esiste modo per verificare l'autenticità del file di progetto video.

Per risolvere il problema, provare una o più delle seguenti operazioni:

  • Richiedere una nuova esportazione video e verificare che la chiave anti-manomissione sia inclusa
  • Esportare di nuovo i dati video tramite un'applicazione di terze parti basata su MIP SDK 2020 R3 o versione successiva
