Aggiunta di telecamere LPR alle viste

  1. In modalità configurazione, selezionare nella scheda Live la vista a cui aggiungere una telecamera LPR.
  2. Nel riquadro Panoramica del sistema, fare clic su LPR e trascinarlo all'elemento della vista interessato.
  3. Nella finestra di dialogo Selezione telecamera LPR, espandere il server richiesto per visualizzare l'elenco di telecamere LPR disponibili di tale server.

Nel riquadro Proprietà sulla scheda Live, si può definire come si desiderano visualizzare gli eventi telecamera LPR (vedere Modifica impostazioni di vista LPR).
